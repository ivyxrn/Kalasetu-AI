# KalaSetu AI (कलासेतु)
> **Bridging Art and Technology** · कला और तकनीक का सेतु  
> A dedicated platform empowering traditional and independent Indian artisans with AI-assisted storytelling, fair pricing, digital cataloguing, and cultural heritage preservation.

---

## 🎨 Overview

**KalaSetu AI** is designed specifically for traditional, folk, tribal, and independent artisans across India—many of whom come from rural heritage clusters and have limited digital experience. It replaces complex, impersonal digital dashboards with a warm, welcoming **Heritage Minimalism** aesthetic inspired by natural Indian earth tones (terracotta, warm ivory, forest green, muted ochre, and soft beige).

---

## ✨ Key Features & Modules

### 1. 📊 Artisan Dashboard
* Welcoming, personalized artisan greeting with daily inspiration quotes.
* Real-time metrics tracking published artworks, generated cultural stories, catalog views, and estimated craft value.
* Quick-access action buttons for immediate workflow execution.

### 2. 🖼️ My Artwork & Fair Pricing Assistant
* Visual artwork management supporting folk styles (Madhubani, Warli, Gond, Pattachitra, Kantha, etc.).
* Comprehensive artwork detail view with provenance, dimensions, materials, and creation year.
* **Fair Pricing Assistant:** An interactive, transparent calculator designed to protect artisans from undervaluation by accounting for material costs, intricate craftsmanship hours, living wages, and fair market margins.

### 3. ✨ AI ArtStory
* Cultural storytelling engine powered by generative AI.
* Generates rich, evocative, and historically grounded narratives in both **English** and **Hindi**.
* Custom narrative lengths (Social Snippet, Standard Story, Detailed Exhibition Lore) and tones (Poetic, Heritage, Contemporary).

### 4. 📖 Digital Catalogue
* Premium art publication feel celebrating traditional Indian arts and crafts.
* Filter by art form, medium, region, and availability.
* Ready for sharing with collectors, galleries, and cultural patrons.

### 5. 🧑‍🎨 My Portfolio ("My Story")
* Conversational, inclusive portfolio experience tailored for traditional artisans without requiring formal qualifications or exhibition histories.
* Guided storytelling prompts: craft heritage, learning lineage, signature techniques, and artisan journey.
* Public portfolio view with one-click export and sharing.

### 6. 🏛️ Heritage Archive
* Digital repository dedicated to preserving endangered Indian art traditions, regional folklore, ancestral techniques, and oral histories.
* Community-friendly documentation interface for oral traditions and craft lineages.

### 7. ⚙️ Preferences & Settings
* Artisan profile customization with local village/town/city provenance.
* Language preference toggle with instant application-wide switching.

### 8. 🤝 Help & Support
* Patient, friendly guide featuring illustrated step-by-step tutorials, searchable FAQs, and an interactive problem reporter with screenshot attachments.

### 9. 🔐 Authentication & Access
* Heritage split-screen login and registration experience.
* Cinematic editorial showcase celebrating living craftsmanship.
* Quick one-click demo login for instant exploration.
* Fully prepared for integration with Supabase Auth (email/password, OAuth, tokenized password recovery).

### 10. 🌐 Complete English & Hindi Bilingual Support
* Centralized internationalization (i18n) system covering every button, modal, form label, error state, and navigation item in authentic English and natural conversational Hindi.

## 🛠️ Technology Stack

* **Frontend Framework:** React 19
* **Build Tool:** Vite
* **Styling:** Tailwind CSS (custom Heritage Minimalism palette: `#F7F3EA`, `#9D4935`, `#354B3D`, `#D5B77A`, `#49372B`, `#EDE3D3`)
* **Icons:** Lucide React
* **Routing:** React Router v7
* **State & i18n:** Custom React Context providers (`LanguageContext`, `AuthContext`)
* **Backend Readiness:** Clean frontend architecture ready for Node.js + Express backend and Supabase / PostgreSQL database integration.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ivyxrn/Kalasetu-AI.git
   cd Kalasetu-AI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📜 Design Philosophy: Heritage Minimalism

KalaSetu AI is crafted with the following core design principles:
* **Respectful Simplicity:** Clear typography, high contrast, and gentle spacing suitable for first-time digital users.
* **Cultural Authenticity:** Authentic traditional color palettes and folk motifs that honor Indian artisan traditions.
* **Artisan Dignity:** Language that centers artisan ownership, creative agency, and fair compensation.
